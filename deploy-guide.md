# MindMirror - Free Deployment Guide

## What You Need
- GitHub account
- Render account
- Groq account
- No credit card required to start on the free plans / free tiers currently offered by those services

## Step 1 - Get Your Free Groq API Key
1. Go to https://console.groq.com
2. Sign up with Google, GitHub, or email
3. Open API keys and create a new key
4. Copy the key for the backend variables on Render

## Step 2 - Push to GitHub
```bash
git init
git add .
git commit -m "MindMirror initial commit"
git remote add origin https://github.com/YOURUSERNAME/mindmirror
git push -u origin main
```

## Step 3 - Deploy on Render
1. Go to https://render.com
2. Create a new Blueprint from your GitHub repo
3. Select the `mindmirror` repository
4. Render will detect `render.yaml` in the repository root
5. It will create the backend, frontend, and PostgreSQL resources

## Step 4 - Set Environment Variables in Render
For the backend service, Render should create these from the Blueprint:

```text
AI_PROVIDER   = groq
GROQ_API_KEY  = set this in the Render dashboard
WHISPER_MODEL = tiny
HF_HOME       = /app/.cache/huggingface
DATABASE_URL  = from the Render Postgres connection string
JWT_SECRET    = auto-generated by the Blueprint
```

If you prefer to set variables manually, use the same values above.

For the frontend service, the Blueprint sets:

```text
NEXT_PUBLIC_API_URL = the backend public URL
```

## Step 5 - Add PostgreSQL
1. Use the Render Postgres database defined in `render.yaml`
2. Make sure the backend service receives the generated `DATABASE_URL`
3. Render will expose the database on Render's private network for the backend

## Step 6 - Seed the Demo Data
After the backend is deployed, open the Render shell for the backend service and run:

```bash
python seed.py
```

## Step 7 - Get Your Public URLs
Render will give you public URLs for both services.

- Backend: your API URL
- Frontend: your web app URL

Use the frontend URL as the project link for demos and submissions.

## Notes
- `AI_PROVIDER=ollama` is still supported for local Docker development
- Render deployment uses `AI_PROVIDER=groq` so the app does not need a local Ollama server
- Whisper uses the tiny model on Render to keep CPU and memory usage low
- The first Hugging Face model load can be slow because the model is downloaded on first use

## Free Tier Limits
- Render: confirm the current account limits in your Render dashboard
- Groq: confirm current request and rate limits in the Groq console
- PostgreSQL: confirm the current free database limits in Render pricing
